# Unprocessed Input

Put new source material here before ingest.

Keep a separate archive copy; Git ignores source files in `input/`. Run
`Do @prompts/start-ingestion.md` to process every readable source file in this
folder. Unrelated topics are handled separately. Files that cannot be read stay
here and are listed in the run summary.

Examples:

- notes
- exports
- transcripts
- documents
- conversation summaries
- copied references
- screenshots or attachment bundles

Input documents do not need to be clean.
