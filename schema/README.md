# Schema

This folder is the human-readable source of truth for the vault.

- `wiki-schema.md` explains the operating model.
- `instruction-transport.md` explains how agent instructions, rules, skills, schema, and wiki files work together.
- `../templates/wiki-entry.md` is the Topic Analysis template.
- `../templates/field-guide.md` is the procedural guidance template.
- `../prompts/start-ingestion.md` is the user-facing ingestion launcher.
- `ingest-workflow.md` describes how input documents become wiki pages.

Update the schema when the operating model changes.
