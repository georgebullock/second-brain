# Daily Curation

Use this skill for the recurring maintenance pass that keeps the second brain
compounding.

## Workflow

1. Read `AGENTS.md`, `DECISIONS.md`, and `schema/wiki-schema.md`.
2. If there are files in `input/unprocessed/`, run `prompts/start-ingestion.md`.
3. Search existing Wiki pages for unsupported claims, unresolved `Open Questions`, and useful missing links.
4. Update existing pages when processed sources provide relevant evidence; cite every changed factual claim.
5. Preserve uncertainty and disagreements. Do not add pages or links based on weak associations.

## Priority Order

1. Preserve source documents and keep one copy of each.
2. Curate high-signal new material.
3. Update existing pages before creating new pages.
4. Improve meaningful links between pages.
5. Record open questions and maintenance recommendations.
