# Synthesize Topic

Use this skill when building or refreshing a topic page from multiple notes.

## Workflow

1. Search curated pages first.
2. Search `input/processed/` for source evidence.
3. Identify the best existing page to update, or choose a new title if needed.
4. Use `schema/ingest-workflow.md` to choose Topic Analysis, Field Guide, or both.
5. Merge overlapping evidence without flattening meaningful differences.
6. Preserve uncertainty, assumptions, decisions, tensions, and contradictions.
7. Link paired Topic Analysis and Field Guide pages; link other pages when they materially inform each other.
8. Add unresolved items to `Open Questions`.

## Evidence

Link every factual claim and prescribed step directly to its supporting
document in `input/processed/`. Use the template selected by the workflow.
